# Paper import

Paper (paper.design) is HTML/CSS. These guidelines are already in that language.

When MCP is connected:

1. `create_artboard` named `Zephrok · Cover` at 1440×900, background `#F6F3EE`
2. `write_html` the cover, colour, type, record, and application frames
3. `get_font_family_info` for Source Serif 4, Source Sans 3, IBM Plex Mono before setting type
4. `get_screenshot` after each frame
5. `finish_working_on_nodes` when done

Do not restyle. Do not add a logo. Ember is `#E24A1B`. Buttons use `#BE3A0E`.
