# Paper import

Living file: https://app.paper.design/file/01M30CXA2B1FCY2C7JM3D714FH/p-1-0

Paper (paper.design) is HTML/CSS. These guidelines are already in that language.

When extending the file:

1. Reuse tokens (`--color-ember`, `--color-ember-strong`, `--font-sans`, …)
2. Keep artboards 1440 wide, `height: fit-content` when content clips
3. `get_screenshot` after each frame
4. `finish_working_on_nodes` when done

Do not restyle. Do not add a logo. Ember is `#E24A1B`. Buttons use `#BE3A0E`.
