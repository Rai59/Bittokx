# Cosmos mark exploration

Space language, universe color, no name in the mark. The company name
may change; these icons do not spell Bit, tok, or x.

Inspired by solar system geometry (star, orbit, axis, gravity, comet,
corona) — original constructions, not stock icon copies.

Open `index.html`.

| Mark | Meaning |
| --- | --- |
| Spark | North star — orientation for the business |
| Halo | World + orbit + satellite (store + AI) |
| Axis | The OS as the pole everything rotates around |
| Well | Gravity pulling the whole stack into one field |
| Drift | Comet — automation in motion |
| Corona | Sun — the engine that keeps running |

Palette: Void `#0A0814`, Star `#F6F0E4`, Solar `#FF8A3D`, Corona `#FFC56A`,
Aurora `#3EE6C8`, Nebula `#7B5CFF`, Plasma `#FF4F9A`, Ice `#6BA6FF`.
