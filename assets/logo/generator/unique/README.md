# Unique mark options

Eclipse is still production. These four are alternatives with a stronger
silhouette — built after it read as clear but not distinctive.

Open `index.html` to compare.

| File | Mark | Idea |
| --- | --- | --- |
| `01-keybit.svg` | Keybit | Circle with a keyway. The OS as the key. |
| `02-operator-b.svg` | Operator B | Custom B whose counters are bits. |
| `03-bit-os.svg` | Bit OS | Rounded square (the OS) with a bite. |
| `04-crosslock.svg` | Crosslock | Solid bar locked through an open bar. The X. |
